Centos7.5离线搭建CDH6.3

Posted on 2019-10-15 Word count in article: 1.3k Reading time ≈ 5 mins.

环境：CentOS 7.5, CDH 6.3

本文记录在 CentOS 7.5 下完全离线部署 CDH 6.3 的完整过程。之前搭建过 CDH 5.x，每次都会遇到一些问题，这次把 6.x 的搭建过程记录下来。

  • 官方文档：Cloudera Enterprise 6.0 安装指南
  • 参考：staroon.dev CDH6 安装

一、搭建前的环境准备

1. 版本与依赖要求

  • 操作系统：RHEL 7.27.5 / CentOS 7.27.5（64 位）
  • Python：2.7+（安装 Hue 需要，不支持 Python 3）、perl、python-psycopg2 2.5.4+
  • Java：仅支持 Oracle 64 位 JDK 8（最低 1.8u31，推荐 1.8u74+）
  • 数据库：生产环境需外部数据库，MySQL 5.7 或 MariaDB 5.5/10.0；库表必须使用 UTF8 编码（不要用 utf8mb4）
  • MySQL 5.7 需额外安装 MySQL-shared-compat 或 MySQL-shared 包
  • 浏览器：Chrome 63+ / Firefox 59+ / IE 11+ / Edge 41+

Web 界面操作要点：

  1. 选择要安装的集群机器；
